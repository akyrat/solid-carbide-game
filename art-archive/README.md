# Art archive

Generated art that is not used in the game. The rule (Visual style, Decisions, and `tasks/README.md`): generated art is archived, never deleted. Only clean, game-ready art lives under `game/art/`; every other generation, test run or rejected version goes here, in a folder named after its task, with its record JSON. This folder is outside `game/`, so Godot never imports it.

`game/art/pixellab-generation-log.jsonl` is a history of every PixelLab call and keeps the original paths; this table maps them to the files here.
