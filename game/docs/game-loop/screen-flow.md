## Screen flow

Task T-055 (Game Loop Agent). `scenes/game/game.tscn` (script `scripts/game/game_flow.gd`, class `GameFlow`) is the project's main scene: pressing F5 in the editor, or `"$GODOT_BIN" --path game`, starts the game on the main menu. The flow is Game loop architecture, Content, "Screen flow".

- **Start** (T-387): the main menu's `start_pressed` calls `_on_menu_start()`. When `GameSettings.load_tutorial_hidden()` is false it calls `show_tutorial()`: the menu is replaced by the tutorial slides (`game.tutorial`, a `TutorialSlides` from `scenes/menu/tutorial_slides.tscn`; [../hud-and-menus/tutorial-slides.md](../hud-and-menus/tutorial-slides.md)) and no run exists yet, so no clock runs. The slides' `start_pressed(dont_show_again)` calls `_on_tutorial_start()`, which saves `GameSettings.save_tutorial_hidden(true)` when the box was ticked, then `start_run()`. When the setting is already true, Start calls `start_run()` at once.
- **`start_run()`** removes the screen on show and starts a fresh run (`scenes/run/run.tscn`), with the pause screen (Escape) added to the run and the camera zoom read from the saved setting. It never shows the slides; the pause screen's Restart calls it too.
- **`GameFlow.tutorial_enabled`** (static, true in the game): the test run sets it false in `tests/helpers/pre_run.gd`, so the many tests and fixtures that press the menu's Start to get a run still get one; `tests/unit/game/test_tutorial_flow.gd` turns it on for its own tests and off again. The screenshot fixtures run outside GUT, so a fixture that presses the menu's Start shows the slides when the save's `tutorial_hidden` is false; `tests/fixtures/tutorial_from_menu_demo.tscn` (and `_3` for slide 3) shows them on purpose, with a fresh settings file.
- **When the run ends,** win or loss (`RunState.run_ended`, which on a health loss comes after the wreck, T-360), `_on_run_ended` reads `run.state.recap()` at once and, deferred, `show_recap(summary)` removes the run and shows the recap screen (T-320, `game.recap`, a `RecapScreen` from `scenes/menu/recap_screen.tscn`; [../hud-and-menus/recap-screen.md](../hud-and-menus/recap-screen.md)). Its `closed` signal (Continue, the X or Enter) calls `show_menu()`. `show_recap()` takes any summary, so another screen (the time's up screen, T-317, or the runs list, T-364) can call it.
- **Garage** (T-089) replaces the menu with the garage screen (`game.garage`, given `game.progress`); its back button (`back_pressed`) brings the main menu back.
- **Exit** closes the game (`get_tree().quit()`, through `quit_game`, which tests replace).
- Only one screen is on show at a time, as the only child of `Game` besides the music: `game.menu`, `game.garage`, `game.tutorial`, `game.run` or `game.recap` (the others are null). `game.pause_screen` is the run's pause screen. The signals `menu_shown`, `tutorial_shown`, `run_shown` and `recap_shown` fire after each switch.
- **Tutorial tests** (T-387): `tests/unit/game/test_tutorial_flow.gd`: Start shows the slides and no run; the clock reads 8:00 after seconds of frames with the slides up; the slides' Start begins the run; ticked saves `tutorial_hidden` and a new game's Start (as after a restart) goes straight into the run; unticked leaves it false and the slides come again; the pause screen's Restart skips the slides. Saves go to test files (T-148).
- **Tests:** `tests/unit/game/test_screen_flow.gd`, part of the GUT suite: the first screen, Start, a win and both kinds of loss to the recap and from its Continue and its X back to the menu (T-320), the recap waiting for the wreck, the recap showing what the run counted, a second run, Garage and its back button, Exit, Escape during a run, and the zoom.
- **Pause screen Restart and Exit** (T-327): `GameFlow` connects the run's `pause_screen.restart_pressed` and `exit_pressed`. Restart banks `run.state.coins` into `progress` (`bank_run("loss", coins)`, so the coins are kept) and calls `start_run()`; Exit banks them and calls `show_menu()`. Both bank through `GameFlow.bank_left_run(progress, run)`, which banks nothing while the car is wrecked (T-413: leaving during the wreck cancels the run; the level creator's Play uses it too; tests in `tests/unit/run/test_wreck_decides_loss.gd`). Neither goes through `run_ended`, so a screen listening for it (the recap) never sees them. The level creator's `play_level` connects the same signals: Restart replays the same level, Exit returns to its list. Tests: `tests/unit/game/test_pause_restart_exit.gd`, `tests/unit/level_creator/test_play_level.gd`.
