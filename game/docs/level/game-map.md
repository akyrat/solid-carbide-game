## The board's level is the game's map (T-372)

(Level design, Decisions, "The board's own level becomes the game's map"; Content, "The game's map".)

- **The file the game plays:** `data/level/kaiju_city_map.json` (`res://data/level/kaiju_city_map.json`): a byte-for-byte copy of the board's level **Kaiju City**, made in the level creator and saved in the creator's levels folder as `data/levels/kaiju_city.json` in the main checkout. That original is the board's working file: it is never written, moved or committed; the copy in `data/level/` is the one in the repo. The copy is never edited to fix it: a problem in it goes to the Project Lead (T-372's result notes list what was found).
- **Where it is chosen:** `GameFlow.GAME_MAP_PATH` (`scripts/game/game_flow.gd`). `start_run()` (the main menu's Start, the tutorial slides' Start and the pause screen's Restart) passes it to `GameFlow.add_run(..., layout_path)`, the same path the level creator's Play uses for its levels (T-239), so the run builds its map, rooftops, ramps, props, boulders, craters, painted ground and the enemies' navigation from the file, and starts the car on its `spawn` (T-280).
- **The elevation sample map stays:** `run.gd`'s default map (`ELEVATION_LAYOUT_PATH`, `data/level/elevation_sample_map.json`) is unchanged, so a run made without a map (the tests, `scenes/run/run.tscn` opened with F6) and the creator keep using it.
- **To play another map from Start:** copy its file into `data/level/` under a new name and change `GAME_MAP_PATH`. Check it first, from the repo root: `python game/tools/check_level.py game/data/level/<file>.json` and `python game/tools/check_height_data.py game/data/level/<file>.json` (both print `OK`).
- **Tests:** `tests/unit/game/test_game_map.gd`: Start (and Restart) play the file; the map holds the file's buildings, rooftops, ramps, props and boulders and draws its own ground; the car starts on the spawn point, on a road, at street level; minions spawn and reach the parked car; a scripted chase with the car parked on the spawn and on every rooftop's centre (every one reached by minions except `roof-13`, which has no ramp up: `NO_WAY_UP`); the kaiju arrives at boss time on open street and walks to the car; its meteors find spots; gift packs land on open road. A report test prints where the minions' spawn ring finds no street (the car on some rooftops), and another line lists the kaiju alert signs drawn on the map. `tests/unit/level_creator/test_creator_end_to_end.gd` checks that Start plays `GAME_MAP_PATH` and that the sample map is still there.
- **Screenshots:** `tests/fixtures/game_map_run_demo.gd` with `game_map_run_{start,wide,rooftop,kaiju,gift}.tscn` (a run from Start; the car parked), e.g. `bash game/tools/screenshot.sh res://tests/fixtures/game_map_run_start.tscn art-archive/T-372/screenshots/start.png 90`. Results: `art-archive/T-372/screenshots/`.
