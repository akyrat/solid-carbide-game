# Recap screen

(The index is [../../README.md](../../README.md).)

## Recap screen

Task T-320 (UI Agent). What the player sees and does: `docs/hud-and-menus.md`, Content, "Recap screen"; where it sits in the flow: `docs/game-loop-architecture.md`, Content, "Screen flow", and [../game-loop/screen-flow.md](../game-loop/screen-flow.md).

- **Files:** `scripts/ui/recap_screen.gd` (class `RecapScreen`, a full-rect `Control`, nearest filtering), `scenes/menu/recap_screen.tscn` (the scene `GameFlow` instantiates as `game.recap`).
- **API:** `show_summary(summary)` shows a `RunState.recap()` dictionary (T-319), replacing what is on show; a summary read back from JSON (the run history, T-363, all numbers floats) works the same, so the runs list (T-364) can reopen a saved run. `closed` is sent once by Continue (`continue_button`), the X (`close_button`) or a fresh Enter / keypad Enter (`_unhandled_key_input`, echoes ignored); `close()` does the same. `is_animating()`, `finish_animation()` (tests and screenshots).
- **For tests:** `title_label`, `sections` (`"enemies"`, `"combo"`, `"tricks"`, `"weapons"` to their panels, only those on show), `enemy_rows[id]` = `{image, name, count}`, `trick_rows[id]` = `{image, count}`, `weapon_rows[id]` = `{image, name, tier}`, `peak_label`, `combo_heat`.
- **T-514 update (supersedes the peak-viewers wording below):** the "combo" section is **Peak combo**: `peak_label` (`PeakMultiplier`) shows T-512's `peak_value` ("x4.25") for `RecapScreen.peak_multiplier(summary)` (= `highest_combo`, at least 1), with `ComboHeat`'s step for that multiplier and the multiplier colour (`multiplier_color()`, `hud.json` `multiplier_tag.color`) at the base. No eye. `ViewersData`, `peak_viewers_for` and the summary's `peak_viewers` are gone; saved summaries that carry `peak_viewers` still load (it is not read). Tests: `tests/unit/test_recap_screen.gd`, `tests/unit/run/test_run_recap.gd`.
- **Text:** every word from `res://data/recap_text.json` (T-318) through `RecapScreen.text("dotted.key")`; the title key from `title_key(summary)` (`win`; `time_up` for `loss_reason` "time"; otherwise `wreck`). Counts use the HUD's count form `WeaponIcons.TEXT_COUNT` ("x{n}", `count_text()`); the peak viewers use the counter's own number format. An id with no text in the file is not shown.
- **Pictures:** enemies: `enemy_image(id)` takes the first square frame of `ENEMY_ART[id]` (`art/minion/minion_s.png`, `art/kaiju/kaiju_s.png`), cropped to its used pixels, cached; weapons: `LevelUpScreen.weapon_image(id)` (the card art, or its placeholder); tricks: `TrickPopupArt.texture(name, "normal", 0)`, the plain popup; Peak engagement (quick tuning, board 2026-10-29: viewers, not a multiplier): `peak_label` shows `ViewersData.format(peak_viewers(summary))` (the summary's `peak_viewers`; for an older summary without it, `RunState.peak_viewers_for(highest_combo)`), after the viewers' eye (`EYE_PATH` `art/hud/eye_icon.png` at `EYE_SCALE` 3); its look is the live viewers counter's: the heat step from `ViewersData.step_for_viewers` (fire takes the top step) applied by its own `ComboHeat` (`set_multiplier` at that step's threshold: colour, glow, pulse), or at the base the viewers colour (`viewers_color()`, hud.json `viewers_counter.color`); the label sits in a fixed-size holder so the pulse's scale is never reset by a container. The X is drawn in code (`CLOSE_GRID`, 12 x 12 at 3x).
- **Order and leaving out:** enemies and tricks follow the text file's key order and are left out at 0; weapons follow the summary (the order taken) and need tier 1 or more; an empty section is left out.
- **Look:** `StyleBoxFlat` panels and buttons (white, 3 px black border, 10 px corners, `anti_aliasing = false`), `Hud.comic_font()`, the main menu's background colour. The buttons have `focus_mode = FOCUS_NONE`. Pop-in: the title then each section, alpha in `POP_STEPS` per `FRAME` (0.04 s), `STAGGER` 0.12 s apart.
- **Tests:** `tests/unit/test_recap_screen.gd` (titles per ending, counts above 0 only, trick popups, weapon card images and tiers, enemy sprites, the peak viewers number, its look and the eye, an older summary without peak viewers, empty sections left out, a JSON summary, every label from the text file, no words typed in the script, Continue / X / Enter close once, no keyboard focus, the X at the top right with nothing overlapping at 1152 x 648, the pop-in, a scripted run); the flow in `tests/unit/game/test_screen_flow.gd`.
- **Screenshots:** `bash game/tools/screenshot.sh res://tests/fixtures/recap_screen_win_demo.tscn <out.png> 90` (also `recap_screen_wreck_demo.tscn`, `recap_screen_time_up_demo.tscn`; fixture script `tests/fixtures/recap_screen_demo.gd`, which isolates the saves with `TestSave.isolate()`). Saved: `art-archive/T-320/screenshots/`.
