# Main menu

(From the old `game/README.md`; the index is [../../README.md](../../README.md).)

## Main menu

The main menu (task T-054, UI Agent): `scenes/menu/main_menu.tscn` with its script `scripts/menu/main_menu.gd` (`MainMenu`). What it shows: `docs/hud-and-menus.md`, Content. The game opens on it through the screen flow (see "Screen flow").

- **Open it:** in the editor, open the scene and press F6. Screenshot, from the repo root: `bash game/tools/screenshot.sh res://scenes/menu/main_menu.tscn screenshots/main_menu.png 20`.
- **Signals:** `start_pressed`, `garage_pressed`, `exit_pressed`, one per button. The menu does nothing else when a button is pressed.
- **Title font (T-432):** Press Start 2P (`fonts/press_start_2p/`, OFL licence and `press_start_2p.json` record; fetched by `python game/tools/fetch_pixel_font.py`) for the title and the "(work in progress)" line, with a near-black outline and nearest filtering.
- **Splash cover slot (T-432):** if `art/menu/splash.png` exists, a `TextureRect` (`splash_rect`, keep-aspect-covered, nearest filtering) fills the screen behind the menu, under a 35% black scrim; otherwise `background` (plain dark navy) shows. `splash_path` can be set before the menu enters the tree to use another image. To preview: `python game/tools/menu_splash_shots.py make`, take the screenshot, then `... remove`.
- **The real splash (T-433):** `art/menu/splash.png` (320 x 180, record `splash.json`) is in place, so the menu shows it (screenshot: `art-archive/T-433/screenshots/main_menu_with_splash.png`). It is PixelLab version 2 of 4, an isometric night crossing with the car at the left and the kaiju at the right; it scored 6/10 in the style loop and is kept for the board's playtest (`docs/visual-style.md`, "The splash cover (T-433)"). Title and buttons stay readable under the 35% scrim, though the car and the zebra crossing sit behind the buttons.
- **Garage button letters (T-535):** `MainMenu.progress` (set by `GameFlow.show_menu` before the menu enters the tree) feeds `can_buy_something()` (any `GarageData.UPGRADES` id with `PlayerProgress.can_buy == OK`); `refresh_garage_pulse()` starts or stops a looping tween that sets the Garage button's text colours (`LETTER_STATES`) between `LETTER_BLUE` and `LETTER_BLUE_PALE` over `PULSE_SECONDS` (1.6), restoring the shared colours when nothing can be bought. No tint, no scale. Tests: `tests/unit/test_garage_button_pulse.gd`. Screenshots: `art-archive/T-535/screenshots/` (fixtures `tests/fixtures/t535_pulse_rich.tscn`, `t535_pulse_poor.tscn`).
- **Tests:** `tests/unit/test_main_menu.gd` (the texts and each signal), part of the GUT suite.
- **Settings button (T-571):** `settings_button` (text `settings_button` from `data/pause_text.json`, through `SettingsScreen.text()`) between Cosmetics and Exit, in the `KeyNav` chain; it emits `settings_pressed`, which `GameFlow.show_settings()` answers.

## Settings screen

Task T-571 (UI Agent; what it shows: `docs/hud-and-menus.md`, Content, "The Settings screen"). `scenes/menu/settings_screen.tscn` with `scripts/menu/settings_screen.gd` (`SettingsScreen`). `GameFlow.show_settings()` replaces the main menu with it (`GameFlow.settings` while it is on screen; `_clear_screens()` removes it) and connects `back_pressed` to `show_menu()`.

- **Shared rows:** `scripts/ui/settings_rows.gd` (`SettingsRows`) holds what the pause screen and this screen share: `slider_row()` (an `HBoxContainer` with the label at `LABEL_WIDTH` 170, an expand-fill `HSlider` without focus, a right-aligned value label at `VALUE_WIDTH` 50; returns `{row, label, slider, value}`), `check()` (the shared checkbox, `HudStyle.style_checkbox`, 16 px square, small text) and `SaveOnRelease`, T-427's slider save rule (`wire(slider, key, saver)` saves on `drag_ended` with a change, `mark(key)` on every change, `save_pending()` on close). `pause_screen.gd` builds its zoom, SFX, music and HUD size rows and its checkboxes with them and keeps its own fields (`music_slider`, `_music_value_label`, ...), so its behaviour and tests are unchanged.
- **Contents:** `ZoomRow`, `SfxRow` (`visible = GameSettings.sfx_enabled()`), `MusicRow`, then `Checks` with `SmoothingCheck`, `DynamicCheck`, `RainCheck`, `DriftGuideCheck`, `JumpArrowCheck`, then `BackButton`. The labels are the pause screen's (`TEXT_ZOOM_LABEL`, `TEXT_SFX_LABEL`, `TEXT_MUSIC_LABEL`, `TEXT_SMOOTHING`, `TEXT_DYNAMIC`, and `rain_label`, `drift_guide_label`, `jump_arrow_label` from `data/pause_text.json`); the title and Back are `settings_title` and `settings_back`.
- **Saves:** every value is read from `GameSettings` in `_ready()`. Sliders: `GameSettings.save_zoom`, `save_sfx_volume`, `save_music_volume` through `SaveOnRelease`; the music slider also calls `GameSettings.apply_music_volume()` at once (the `MusicPlayer` plays on the Music bus, so the menu's music follows), the SFX slider `apply_sfx_volume()`; the zoom only saves (no camera here; `GameFlow.add_run()` reads it). Checkboxes save at once: `save_camera_smoothing`, `save_dynamic_camera` (no camera here; `run.load_camera_options()` reads them at the next run), `save_rain_enabled`, `save_drift_guide_enabled`, `save_jump_arrow_enabled`.
- **Leaving:** `go_back()` (Back, and the `pause` action, Escape, in `_unhandled_input`) calls `save_pending()` and emits `back_pressed`.
- **Keyboard:** focus starts on Back; `_link_focus()` sets the neighbours: Back up and down to the first checkbox, the checkboxes left and right round the row and up and down to Back. W, A, S, D through `KeyNav.handle_wasd`.
- **Tests:** `tests/unit/test_settings_screen.gd` (the button, the exact controls with the SFX switch off and on, Back and Escape, read at open, music heard at once and one write on release, saved on Back, checkboxes saved at once, the values on the pause screen of the next run and in a fresh game flow, a pause screen change shown here, the keyboard order); `test_menu_arrow_keys.gd` and `hud/test_shared_button.gd` count the new button.
- **Screenshots:** `bash game/tools/screenshot.sh res://tests/fixtures/t571_settings.tscn out.png 30` (also `t571_settings_sfx.tscn` with the SFX switch on, `t571_menu.tscn` the menu with Settings selected); the fixture uses a throwaway settings file. Saved in `art-archive/T-571/screenshots/`.
